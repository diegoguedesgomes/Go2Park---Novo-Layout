# Go2Park Design System

Este workspace contem uma primeira versao do novo design system da Go2Park.

## Arquivos

- `docs/design-system.md`: guia de marca, tokens, componentes e aplicacao.
- `docs/tokens.go2park.json`: tokens prontos para dev/design handoff.
- `index.html`: preview visual navegavel do sistema.
- `empresas.html`: landing page B2B para estacionamentos e operadores de traslado.
- `clientes.html`: landing page B2C para passageiros acompanharem/entenderem a van.
- `css/landing-pages.css`: estilos compartilhados das landing pages.
- `assets/`: logos e mockups copiados dos arquivos de referencia.

## Direcao Criativa

A Go2Park passa a operar em uma base mais precisa e B2B: canvas branco, navy operacional, azul de marca como acao principal e verde-lima como sinal de eficiencia. A referencia Webflow foi usada pela disciplina de sistema, nao como copia estetica literal.

Abra `index.html` no navegador para revisar os componentes e exemplos.
